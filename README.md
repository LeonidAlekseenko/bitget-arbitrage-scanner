# SpreadPulse: BTC Spot-Futures Arbitrage Advisor

A real-time arbitrage monitoring tool between Bitget Spot and USDT-Futures markets built with Python (FastAPI, WebSockets) and JavaScript (Chart.js).

## Requirements
`pip install fastapi uvicorn websockets`

## How to run
1. Run `python3 server.py`
2. Open `http://localhost:8000` in your browser.
